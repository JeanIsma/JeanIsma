The current README uses `assets/v2/`. Rebuild with `node design/build-cinematic.cjs` after installing `sharp`. The script accepts the committed `cinematic-source.jpg` and `simpletrain-demo.jpg` sources. Original PNGs, when locally available, are used for first-generation exports.

- The new landscape and glass sculpture are original AI-generated artwork created for this profile. They do not depict a documented installation at an identified place.

- GHS and ReleaseGuard illustrations are conceptual, with no proprietary screenshots or business data.

The framing step preserves its original viewBox and contribution animation, adds a matching frame and respects reduced-motion preferences. The workflow publishes to the existing `output` branch twice daily and after updates to `main`.
- The hero has separate desktop and phone artwork, with static PNG alternatives for reduced motion. Other SVGs disable their CSS animation for reduced-motion preferences.

The original design assets below remain available as historical source material.

The profile is a GitHub README, with self-contained animated SVG illustrations and readable Markdown. No custom page CSS, scripts, external badges, stats servers or background requests are required by the README artwork.

## Rebuilding

Run `npm install --no-save sharp`, then `node design/build-assets.cjs` from the repository root. The script reads `landscape-source.png` when present; the committed JPEG source is the portable fallback.

The main SVG is 1600 × 1000. Its text stays still while the glass lens, reflections and status light move. All SVGs disable animation with `prefers-reduced-motion: reduce`; the hero additionally has a static PNG alternative in the README. The photo and logo are embedded so GitHub image rendering needs no nested remote fetches.

GitHub removes scripts and inline styling from README markup: https://github.com/github/markup. Animation is inside the SVG assets. Mobile layouts use scalable image widths and standard Markdown content; contact and project links also exist as text.
